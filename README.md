# Compilador CSD

##  Descrição

O **Compilador CSD** é um compilador básico de uma linguagem funcional desenvolvido do zero com fins didáticos e acadêmicos desenvolvido na Linguagem C. O projeto é capaz de **analisar, compilar e executar códigos**, além de **identificar e reportar erros** ao usuário de forma clara.

O compilador também conta com uma interface gráfica, que auxilia na visualização do processo de execução, incluindo o acompanhamento da **memória** e da **alocação de variáveis**.

---

## Funcionalidades

- Análise léxica, sintática e semântica da linguagem.
- Compilação e execução do código fonte.
- Detecção e exibição de erros no programa.
- Interface gráfica para visualização da execução.
- Exibição da memória e alocação de variáveis durante a execução.

---

## Como Rodar o Projeto
1. Clone o repositório:
```bash
git clone https://github.com/LarryFilho/Compilador-CSD.git
cd Compilador-CSD
```
2. Execute "CompiladorCSD.exe".
3. Clique em "Compilar & Executar" e em seguida em "Executar".

## Observações sobre o Projeto

O código que está sendo executado ao rodar o programa logo que feito o clone do repositório é uma simples multiplicação por 2 do número inserido pelo usuário. Caso o usuário deseje alterar o código que está sendo executado existem 2 opções:

**1.**  Alterar o que está dentro "arquivo.txt", salvá-lo e depois ir em "Abrir Arquivo" e selecionar novamente "arquivo.txt".

**2.** Criar um novo arquivo .txt fazer todo o código e depois carregá-lo da mesma maneira que no passo 1.
